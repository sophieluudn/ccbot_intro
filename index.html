  • 自然語意解析

  • 完整保留對話歷史
  • 提升關鍵情境體驗
系統架構

模組化三層架構

整合用戶互動、對話分流與知識服務
支援多元業務場景，提供高彈性、高擴充性的功能

使用者介面層

支援多元對話入口，如 Web、APP、社群平台 (Line / FB) 等，提供統一的互動體驗。

核心對話層

搭載 Dialogflow 語意解析與分流邏輯，動態判斷應進入腳本、AI 搜尋或真人轉接。

知識服務層

結合 AI Search、向量資料庫與生成式 AI 模型，針對複雜問題進行檢索與生成建議。

使用者介面層介介接方式

Web

以嵌入方式 (iframe) 整合於主網站，用戶瀏覽網站時即可展開即時交談視窗。

APP

透過 APP 內嵌方式 (webview) 開啟聊天服務，確保移動端與網站擁有完全一致的使用體驗。

社群平台 (FB / LINE)

透過 Messenger / LINE API 與核心層串接，用戶可直接於習慣的社群平台與機器人對話。

會員串接架構流程

實現會員身分識別與個人化服務的協作架構

1

用戶從 Chatbot 透過主站會員機制，進行會員登入 / 註冊的驗證

2

主站會員機制驗證成功後，取得會員相關資訊回傳給 Chatbot

訊息樣式

多種訊息回應樣式
滿足多元溝通情境

從基礎文字到豐富的圖文選單、按鈕卡片，以多樣化的視覺呈現，精準引導用戶操作

文字選項卡 快速選項 一般選項卡 圖片 影片選項卡 音頻選項卡
AI 知識庫

建立 AI 知識庫

彈性化知識導入機制，AI 可持續同步最新業務資訊
確保知識即時更新

首次批次匯入

一次性匯入既有歷史資料，快速建置初期知識庫基線，確保系統啟動即具備可用資訊基礎

API 自動同步

串接外部系統或既有 API，依排程或事件機制持續同步更新資料，確保知識內容即時性與一致性

後台手動編輯

提供後台操作介面，支援即時新增、編輯與維護知識內容，強化彈性調整與控管能力

真人客服

真人客服銜接

由專人客服提供進一步諮詢與協助，確保問題得以妥善處理

真人客服呼叫流程

透過主站會員登入／註冊機制完成身份驗證，並將會員資料同步至 Chatbot。

Chrome 瀏覽器即時通知

使用者發起真人客服需求時，系統即時透過 Chrome 通知客服人員，確保能迅速回應解決用戶問題。

後台接管對話

客服人員可於後台查看完整對話紀錄，並隨時接管對話進行後續服務，讓 AI 與真人無縫切換。
